Card states

The center column holds only identity, the secret, and the action; the status line exists only when there is something to say — errors, prompts, transient notices — so the card stays tight at rest. Choosers appear only when there is a choice; the refresh control lives inside the session menu.

Corner controls

Larger text and high contrast return as two icon toggles beside the power icon; restart and power off keep the two-step popover confirm. The Orca launcher joins only when screen_reader is configured.
