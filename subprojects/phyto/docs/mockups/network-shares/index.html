SAVED NETWORK DEVICE

Add connection

Save a network location to find it again in Places.

Use smb://, sftp://, davs:// or dav://. Do not include a password.

Reconnect

Saving a connection does not save its password. You can choose to remember credentials when signing in.
AUTHENTICATION PREVIEW

Sign in to your server

Your server needs authentication

Phyto will show the provider’s sign-in prompt here. Password remembering is a separate choice, handled by your desktop keyring.

This demo uses fictional credentials. No password is requested or stored.

Forget connection?

This removes the saved device and its reconnect preference. Remote files and any current mount remain. Disconnect separately if needed.
